# Marca: logo CE

Logo de Chileconomics: **C** de Chile y **E** de Economics. Los brazos de la E tienen largos
distintos (corto, medio y largo) y forman un gráfico de barras.

- La C es la letra Montserrat Medium convertida en trazos, así que no depende de fuentes instaladas.
- La E se dibuja con rectángulos del mismo grosor que la E de Montserrat Medium.

## Colores

| Modo   | Fondo     | Letras    |
| ------ | --------- | --------- |
| Oscuro | `#0f172a` | `#e2e8f0` |
| Claro  | `#f5f7fb` | `#0f172a` |

## Archivos

| Archivo                                  | Uso                                                                 |
| ---------------------------------------- | ------------------------------------------------------------------- |
| `logo-oscuro.svg`, `logo-claro.svg`       | Logo cuadrado con fondo. Vectorial: sirve para cualquier tamaño.    |
| `simbolo-para-fondo-*.svg`               | Solo las letras, sin fondo, para poner sobre otra imagen o video.   |
| `logo-*-2048.png`                        | Logo cuadrado de 2048 × 2048 px (redes sociales, presentaciones).   |
| `simbolo-para-fondo-*-4000.png`          | Letras sin fondo (PNG transparente) de 4000 px de ancho.            |
| `video-4k-*.png`                         | Cuadro de video 4K (3840 × 2160) con el logo centrado.              |

El ícono del sitio (`public/favicon.svg`) es el mismo logo y cambia solo entre claro y oscuro según
el tema del sistema del visitante.

Para cualquier tamaño nuevo conviene partir de los `.svg`: al ser vectoriales no pierden calidad.
